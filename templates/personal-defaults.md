# Personal defaults (global across projects)

Promote only what the user explicitly marks as personal-default.

## Design (Shahid global defaults)
- No eyebrows on public marketing UI
- Seamless sections; minimal gaps; no thin divider separators by default
- Minimal planned palette discipline
- Research before design; re-research on redesign requests
- Cleanup/quality gate before every submit
- Workspace hygiene: no duplicate assets; organize drops

## Workflow
- `/sps` required on projects that use it
- CMS-coupled section delivery when CMS is enabled
- `/sps sync` for legacy CMS debt
