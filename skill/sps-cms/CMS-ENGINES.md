# Dual CMS Engines: In-Context Visual & Collection Hub

SPS-CMS provides a true WordPress/Webflow-grade client editing experience divided into two complementary engines:

---

## 1. Engine A: Visual In-Context Live Page Editor

Engine A is designed for **Singleton Page Sections** (Hero banners, Badges, Headlines, Subtitles, Stats, CTA Buttons, and Section Headings).

```
┌────────────────────────────────────────────────────────────────────────┐
│               ENGINE A: VISUAL IN-CONTEXT LIVE ARCHITECT               │
├────────────────────────────────────────────────────────────────────────┤
│ • Zero Accidental Redirection:                                         │
│   In Edit Mode, clicking any CTA/button NEVER redirects the browser.   │
│                                                                        │
│ • Floating Contextual Inspector Popover:                               │
│   Clicking any button/link opens an instant Glassmorphic Popover:      │
│   ┌──────────────────────────────────────────────────────────────────┐ │
│   │ 🔗 Edit CTA & Link Destination                                  │ │
│   │ Visible Label:  [ Explore Top Packages ]                         │ │
│   │ Destination URL:[ /packages            ] [ Quick presets ]       │ │

│   │                 [ Cancel ]  [ Apply Updates ✔ ]                  │ │

```

---

## 2. Engine B: Centralized Polymorphic Collection Hub

Engine B is designed for **Repeater & Dynamic Data** (Tour Packages, Real Estate Listings, Products, Doctors, Menu Dishes).

- **WordPress/Shopify-Style List Table:** Search, filter by status, instant `[ON/OFF]` Homepage switches.
- **Inspector Sidebar & Slugs:** Auto-slug generator with collision prevention, categories, image dropzone, and repeater blocks (Itineraries, FAQs).
- **Gemini Flash AI Auto-Translate:** Single-click translation sync across all target languages.
