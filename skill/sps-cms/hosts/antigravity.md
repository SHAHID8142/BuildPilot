# Antigravity Host Adapter for SPS-CMS

## Path
`~/.gemini/config/skills/sps-cms`

## Discovery & Triggers
Antigravity automatically discovers skills in `~/.gemini/config/skills/`.
Triggers include:
- Mentioning "CMS", "admin panel", "content management", "WordPress", "Shopify"
- Mentioning "Astro CMS", "Next.js CMS", "tour packages", "products", "services"
- Slash command `/sps-cms` or explicit request to build an admin system.

## Enforcements on Antigravity
1. Execute mandatory Step 0 Discovery Grill before modifying code.
2. Ensure Zero-SaaS law (Hostinger/cPanel MySQL, SQLite, local `/public/uploads`).
3. Wire both Engine A (Live Editor) and Engine B (Collection Manager).
4. Run roundtrip DoD verification before task handoff.
