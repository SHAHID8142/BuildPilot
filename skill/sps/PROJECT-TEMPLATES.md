# Project Templates

Use these templates to scale discovery and planning to the project type.

## Marketing / Landing Page

Focus on:
- brand
- messaging
- section hierarchy
- motion tolerance
- mobile clarity
- performance

Likely systems:
- no CMS or a light CMS
- little or no admin
- little or no ERP

## Portfolio / Personal Brand

Focus on:
- visual identity
- case study structure
- media assets
- motion restraint vs flair
- low-end mobile polish

Likely systems:
- simple contact / form flow
- minimal backend

## SaaS Product

Focus on:
- product IA
- auth
- app shell
- dashboard structure
- billing
- onboarding
- documentation

Likely systems:
- admin roles
- analytics
- email

## E-commerce / Storefront

Focus on:
- catalog
- product detail
- cart and checkout
- CMS content blocks
- search / filtering
- inventory / order flow

Likely systems:
- storefront
- CMS
- admin
- ERP or inventory integrations

## Dashboard / Admin

Focus on:
- data density
- permissions
- states and fallbacks
- table / filter / detail workflows
- responsiveness on smaller laptops and tablets

Likely systems:
- auth
- roles
- analytics
- admin tools

## CMS-heavy Site

Focus on:
- content model
- editorial workflow
- preview flow
- SEO ownership
- media management

Likely systems:
- CMS
- search
- forms

## ERP / Operations System

Focus on:
- entities and workflow states
- permissions
- approvals
- reporting
- low-latency interactions
- operational integrity over visual flourish

Likely systems:
- admin
- ERP
- integrations
- audit trails
