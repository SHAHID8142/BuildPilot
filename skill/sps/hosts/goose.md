# Goose (Block) host adapter

1. Skills dir: `~/.config/goose/skills` (or `~/.goose/skills`); installed by
   `install.sh` / `npx skills add ... --agent goose`
2. Follow METHOD-CARD + SKILL.md portable steps
3. Goose has no native plan-approval UI — SPS gates (G1/G2/approval packets)
   run as conversational stops; do not proceed without the user's reply
4. MCP extensions are available but optional; never assume a specific
   extension is installed (Tool Consent law applies)
5. Write `./.sps/agent.md` with `host: goose`
