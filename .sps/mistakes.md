# SPS Mistake Log
Project-local mistakes only. Do not use this file for global cross-project rules.

When recording a mistake, include:
- what happened
- why it happened (hallucination, skipped mobile gate, missing memory write, etc.)
- the correction
- date / active agent if known
- similar count (for promotion review)

After 2+ similar mistakes, follow `MISTAKE-PROMOTION.md`.
