**What you're deciding:** whether we know enough about your project to start building it.

Hello! Before we build anything for **{project}**, we need to ask you a few short questions. Your answers tell us what to make and how to make it.

**Why now:** if we guess instead of asking, we waste your time and money building the wrong thing. So we ask first, and build only after you answer.

**What we need from you:**

1. What is the website for? (Sell things? Get calls? Share information?)
2. Where should it live online? (We can suggest a home if you don't have one.)
3. What tools or limits should we follow, if any?
4. What words and pictures will you give us, and what should we write ourselves?
5. Do you want to edit the pages yourself later? (Most clients say yes — we set that up.)

**What happens next:** you answer, we write your answers down in the project file, and then we start. If a question does not apply to you, just say "none" — that is a real answer and it helps us.
